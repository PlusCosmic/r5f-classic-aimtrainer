Aim Trainer (Classic) for R5 Flowstate
======================================

A port of the R5Reloaded Flowstate aim trainer: 15 drills, live stats,
results, session history, saved loadouts, preset routines and playlists.

You need R5 Flowstate installed and launched at least once.

Install
-------
1. Close the game.
2. Extract this zip anywhere (not inside the game folder is fine).
3. Double-click Install.bat. It finds your game from the R5 Flowstate
   launcher; if it can't, it asks you to pick the folder that has
   r5apex_dx12.exe in it.

Play
----
Double-click "Play Worlds Edge.bat" (or "Play Firing Range.bat"). It starts
a local server on the aim trainer mode and joins it. The mode does not show
up in the launcher's Play Local list, so always start it this way. Leave the
black window open; closing the game stops the server.

Add -Windowed to the .bat's command line for windowed mode.

In game: pick a challenge, or set up routines/playlists on the ROUTINES tab.
Hold Reload to finish a drill early. Your settings, loadouts, presets and
playlists are saved between sessions.

Update / uninstall
------------------
Updating: extract the new zip and run its Install.bat. Your saved stuff stays.
Uninstall.bat removes the mod and its menus.

If something breaks
-------------------
A launcher "repair" can remove the menus; just run Install.bat again.
If Windows blocks the .bat files: right-click the zip > Properties >
Unblock, then extract again.
